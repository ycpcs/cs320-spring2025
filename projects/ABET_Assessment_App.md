Project Summary
===============
Design and develop a platform to allow professors to enter assessment data via a web form. The application should display for each professor only the courses/outcomes/indicators they are responsible for in a given semester. The assessment director should be able to associate professors with courses and provide a schedule of which courses will be assessed in each semester. They system should then be able to provide the assessment director with a view of which assessments have been completed and which ones are still outstanding. It should also be able to generate a report for each year and assessment cycle aggregating all the data collected during that assessment period

Basic Requirements
==================

* Separate logins for each professor

* A mapping of courses to professors for each semester

* A table of outcomes and corresponding indicators

* A table of which outcome/indicators correspond to each course and whether they are formative or summative

* A(n) (editable) table containing the assessment schedule for the entire assessment cycle

* A(n) (editable) table of target achievement levels by course

* A web-based form where professors can enter data regarding the assessment measure used and the resulting data collected for that measure. It would be helpful to be able to display the previous assessment performed in the course for the selected outcome/indicator.

* The ability to generate a summary for all outcomes/indicators for a given year and entire assessment cycle
